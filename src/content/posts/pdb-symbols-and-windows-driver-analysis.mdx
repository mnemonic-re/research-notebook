## Introduction

Symbolic information provided by Microsoft Public Symbol Server provides critical context during static binary analysis. Function names, global structure definitions, and type signatures reduce time spent reverse engineering standard framework boilerplate.

```c
// Test C / Driver Code
NTSTATUS DriverEntry(
    _In_ PDRIVER_OBJECT DriverObject,
    _In_ PUNICODE_STRING RegistryPath
) {
    UNREFERENCED_PARAMETER(RegistryPath);
    
    DriverObject->DriverUnload = SampleUnloadRoutine;
    DriverObject->MajorFunction[IRP_MJ_CREATE] = SampleCreateClose;
    DriverObject->MajorFunction[IRP_MJ_CLOSE] = SampleCreateClose;
    DriverObject->MajorFunction[IRP_MJ_DEVICE_CONTROL] = SampleDeviceControl;

    return STATUS_SUCCESS;
}
```

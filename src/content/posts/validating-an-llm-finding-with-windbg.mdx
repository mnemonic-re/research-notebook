## Overview

When using LLMs to analyze disassembled binary routines or decompiled C code, the model may suggest potential memory safety issues or unvalidated pointer dereferences. Static suggestions must always be dynamically verified in a controlled kernel debugging setup.

## Debugging Setup

In WinDbg connected to a target test VM over KDNET, we can set conditional breakpoints on candidate IOCTL dispatch routines.

<Command>
!analyze -v
bp nt!IopSynchronousServiceTail "+r; g"
</Command>

<Note>
Always verify symbol resolution before setting breakpoints on unexported functions or driver dispatch tables.
</Note>

```text
mov     rdi, rcx

```
